# Directory submission (internal)

Use this when filling vendor forms.

**Skill name:** eonik

**Description:** Set eonik up for a brand, watch its competitors' ads, read its own, and have the
eonik app on the person's Mac make every size of an ad, on-brand, checked, sent for approval and
delivered. Never launches ads, moves budget, buys anything or makes a choice that is the person's.

**GitHub URL:** https://github.com/eonik-ai/eonik-mcp-skill

**Extra information:** Agent Plugins 1.0 package with the remote MCP server
`https://api.eonik.ai/mcp` (OAuth). Local fallback: `npx -y eonik-mcp@5.0.0` with
`EONIK_API_KEY` (`EONIK_BRAND_ID` optional), or `npx eonik-mcp init` to connect every assistant on
a computer. No secrets in the repository. MIT-0.

**Related plugins:** None.
